# Decision Graph Simulator

Monorepo for the Decision Graph Simulator (backend, frontend, desktop).

This repository contains multiple components; detailed phase progress and validation artifacts are tracked in the `completion status/` folder. For Phase 3 details see:

- [completion status/phase3_v0.1_completion.md](completion%20status/phase3_v0.1_completion.md)

Quick start (backend):

1. Create and activate a Python virtualenv in the `backend` folder.
2. Install dependencies (Poetry):

	poetry install

3. Run tests:

	poetry run pytest -q
